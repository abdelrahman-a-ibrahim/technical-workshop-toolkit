# Evidence register

No measured results yet. This folder starts empty apart from this guide.

For each completed experiment, save a small sanitized report with:
- Commit, date, environment and dependency versions.
- Exact reproduction command, input size, workload and duration.
- Raw observations, measurement method and relevant failure injection.
- Baseline and comparison under equivalent conditions, if claiming improvement.
- Interpretation, uncertainty, environment limitations and cleanup.

Use synthetic service names and data. Inspect logs, screenshots and exports for tokens, personal information and infrastructure identifiers before publishing. Do not store huge dumps or secrets here; summarize and retain only the smallest reproducible evidence.

A future case study should say “independent lab experiment” and describe exactly what was built. Never describe a planned milestone, illustrative fixture or employer result as a measured result from this repository.
